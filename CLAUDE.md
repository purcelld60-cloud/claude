# Da Roça Adventure

Leia primeiro [AGENTS.md](AGENTS.md) e [README.md](README.md). As mesmas orientações valem para Claude Code e outros assistentes.

Para executar a cópia local: `python3 tools/dev-server.py`, depois abra `http://127.0.0.1:8080`.

O código do cliente fica em `dist/`; o backend em `worker/`; migrações em `drizzle/`; aplicativos em `native/`. O guia [docs/MODIFICAR-COM-IA.md](docs/MODIFICAR-COM-IA.md) contém exemplos de pedidos e o procedimento para criar uma distribuição independente.

Preserve a campanha, os saves, os controles e a continuidade de áudio ao fazer alterações. A cópia pública não inclui credenciais nem a chave do aplicativo oficial.
